# 法典｜法條精準記憶系統

LexCore｜Precision Law Memorization System

版本：`v0.14.7`

這是本地端、可離線使用的法條背誦訓練系統第一個可執行版本。法規、法條原文、作答、錯題、熟練度與備份都留在瀏覽器 IndexedDB；第一版不使用登入、雲端 AI、分析追蹤或外部 API。

## 快速開始

需要 Node.js 18 以上。標準 Node 環境可使用：

```powershell
npm install
npm run dev
```

開發伺服器啟動後，以瀏覽器開啟 `http://localhost:4173`。應用程式本身不需要後端伺服器；開發伺服器只負責提供前端檔案。

```powershell
npm run test
npm run build
```

本工作區的 Windows 環境沒有全域 `node`/`npm`，驗證時使用 Codex 提供的可攜式 Node 與 `pnpm.cmd` 完成同等的依賴安裝、測試及建置；一般使用者仍可依上面的 npm 指令執行。

正式版輸出在 `dist/`。若要用靜態伺服器檢查 production build，可使用任何只提供檔案的本機 HTTP 伺服器；不需要建立 API 或資料庫。

## 第一輪驗收流程

1. 到「法規管理」建立一部法規。
2. 到「法條瀏覽」貼上多條包含 `第1條`、`第 2 條` 或 `第　三　條` 的文字。
3. 按「產生拆分預覽」，修改條號、原文、重要程度、必背與每日任務標記。
4. 按「確認並儲存」寫入本機 IndexedDB。
5. 在法條列按「訓練」，依序完成全文閱讀、構成要件／法律效果／刑罰選擇題、段落排序、數字陷阱與應／得用語陷阱。
6. 在法條瀏覽上方選擇法規；每一條法條可按「筆記／考題」保存個人筆記、歷屆題目與混淆陷阱。
7. 查看每個選擇題的正解、原文語境、錯題、下次複習與熟練度。
8. 到儀表板、今日任務、錯題中心、熟練度分析與學習紀錄查看結果。
9. 在「備份與還原」下載 JSON；需要清空後驗證時，可在設定使用重置，再以「覆蓋現有資料」還原。

警佐班使用者可在「法條瀏覽」的官方匯入頁直接套用「警佐班四科法條核心」。系統依中央警察大學最新公開的 115 年警佐班第 46 期簡章建立「憲法、警察法規、刑法、刑事訴訟法」四類，從法務部全國法規資料庫補入 8 部法律，並另外取得 2 部現行警察法規子法：違反社會秩序維護法案件處理辦法、地方法院與警察機關處理違反社會秩序維護法案件聯繫辦法；既有同條號資料不覆寫，官方標示刪除的條文會略過。116 年（2027）簡章公布後仍應再次核對範圍。

第一次在新的瀏覽器或裝置開啟時，系統會自動將目前這套四科核心法條建立到本機 IndexedDB；完成後每次開啟都直接讀取本機資料，不會重複匯入。若清除網站資料或使用無痕模式，瀏覽器會視為新的裝置，重要進度請先備份。

日後可在「法條瀏覽」的「全國法規資料庫」頁籤搜尋現行法規、逐條勾選並匯入；資料會以部署時建立的法務部官方資料鏡像提供，避免瀏覽器跨網域限制。另有「外部警察法規命令」頁籤，可建立未收錄於官方索引的警察機關作業規定、函釋整理或其他命令，匯入 TXT／JSON 後先預覽再儲存。法條瀏覽會依條號自然排序，並以第幾項、款、目標示原文結構，原始內容不會被改寫。

刑事訴訟法另內建使用者提供的 120 個爭點考頻排行。系統將前 15 名標為 S 級、第 16–40 名標為 A 級，並把能明確對應的刑訴法條提高為必背、優先放入每日任務及訓練清單；法條瀏覽可隨時切回「條號順序」。跨法規、解釋或純實務爭點會保留在排行中，不會勉強連到錯誤條文。此排行不是官方統計，法條原文仍以官方資料鏡像為準。

訓練頁的「數字陷阱」會自動從已匯入法條辨識刑度、程序期間、年齡、金額／罰鍰、比例、人數／次數與距離／重量，將目標數字遮住並產生四個同單位近似選項。數字題採 0／100 精確判定；答錯會連同完整法條原文、誤選值與正確值寫入錯題及間隔複習。

「法規體系圖」會依官方章、節、款資料及法條順序，自動整理每部已匯入法規的架構、條文範圍與熟練度。預設只看骨架，也能展開條文並直接進入該條訓練；未分章的法規仍會依條號建立完整導覽。

憲法增修條文明文記載「停止適用」的憲法條文，會在載入本機資料時自動封存，不再顯示、建立每日任務或重新匯入；僅停止部分規定的條文會保留。封存仍會留在本機備份資料中，方便追溯。

首頁提供「載入示範資料」僅供操作驗證。所有示範法條會標示「示範資料，非正式法條內容」，不應當作正式法規來源。

## IndexedDB 資料表

資料庫名稱為 `lexcore-local`。目前的 stores 如下：

| Store | 用途 |
| --- | --- |
| `settings` | 考試日期、每日目標、比對選項、權重、複習間隔、關鍵詞 |
| `laws` | 法規名稱、簡稱、分類、重要程度、考試範圍、備註；刪除採封存 |
| `articles` | 條號、原始全文、標題、重要程度、必背/每日/魔王標記 |
| `sections` | 法條分段及項、款、目分類，供排序與後續擴充 |
| `sessions` | 每次閱讀或訓練的時間、模式、分數、提示次數 |
| `answers` | 完整作答原文、答案與完整 `ComparisonResult` |
| `errors` | 錯字、漏字、多字、替換、高權重與結構錯誤 |
| `reviews` | 熟練階段、間隔、下次複習、連續答對、跨日紀錄 |
| `mastery` | 每條法條的模式平均、熟練度、狀態、精通條件證據 |
| `tasks` | 每日任務類型、法條、預估時間與完成狀態 |
| `achievements` | 已解鎖成就 |
| `confusions` | 使用者手動建立的易混淆法條組 |
| `progress` | 等級、XP、連續學習、總答題數與學習日期 |

## 文字標準化與逐字比對

比對前會依設定處理標點、空白、換行、全形/半形及阿拉伯/中文數字；預設只忽略標點、額外空白、換行與全半形，不忽略文字與法定用語。資料庫永遠保留使用者匯入的原始全文。

`compare.ts` 使用 Levenshtein 動態規劃產生字元級 diff，分辨：

- 替換（錯字）
- 期望文字未出現（漏字）
- 答案多出的文字（多字）
- 高權重關鍵詞不一致
- 項、款、目或結構 token 順序不一致

評分公式：

```text
最終分數 = 逐字正確率 × 50%
         + 關鍵字正確率 × 25%
         + 結構正確率 × 15%
         + 無提示分 × 10%
```

高權重關鍵詞或結構錯誤會把分數上限壓到 94，避免高整體正確率錯誤地取得 S。分級為 S=100、A=95–99、B=90–94、C=80–89、D=70–79、E=69 以下。

## 熟練度與狀態

目前訓練流程為：全文閱讀、構成要件／法律效果／刑罰選擇題、段落排序、數字陷阱、應／得用語陷阱。閱讀只留下閱讀紀錄，不直接把法條判定為背熟；熟練度由理解題、排序、數字與用語陷阱的多次表現及跨日穩定度累積。舊版提示默寫與完整默寫作答紀錄仍可在備份中保留，但新介面不再提供這兩種模式。

「已精通」還必須同時滿足：

- 核心理解與陷阱題平均 95 分以上
- 至少三個不同日期核心題 95 分以上
- 連續三次核心題 95 分以上
- 七日以上間隔複習仍達 90 分
- 沒有高權重關鍵詞錯誤與結構錯誤

狀態會由「未開始、初次接觸、學習中、尚未穩定、接近熟練、已熟練、已精通、高風險、需要重新學習」中選擇。單次高分不會直接進入精通。

## 間隔複習

預設間隔為 `0.007、1、3、7、14、30、60、90` 天，第一個間隔約 10 分鐘。高分且無提示會進入下一階段；90 分以下會回到短間隔並增加 lapse；使用提示時不會大幅延長間隔。排程、作答與熟練度是分開保存的資料，方便稽核與後續調整。

## 備份格式

JSON 外層格式如下：

```json
{
  "format": "lexcore-backup",
  "version": "0.1.0",
  "exportedAt": "2026-08-02T00:00:00.000Z",
  "settings": {},
  "laws": [],
  "articles": [],
  "sections": [],
  "sessions": [],
  "answers": [],
  "errors": [],
  "reviews": [],
  "mastery": [],
  "tasks": [],
  "achievements": [],
  "confusions": [],
  "progress": {}
}
```

還原前會驗證 `format`、必要陣列、設定與進度。覆蓋模式清除目前本機 stores 後寫入備份；合併模式以法規名稱、法條所屬法規與條號、法條 ID、任務日期/法條/類型等鍵避免重複，並會把同名法規及相同條號的關聯 ID 對應到目前資料。

## 已知問題與安全邊界

- 官方匯入資料來自法務部公開資料集；如與主管機關公布內容不同，仍以主管機關公布內容為準。
- 進度預測是依目前紀錄與每日容量的估算，不是考試結果保證。
- 瀏覽器的無痕模式、清除網站資料或手動刪除 IndexedDB 可能導致資料消失；重要資料請定期匯出 JSON。
- PWA 安裝與離線快取需要先以 HTTP/HTTPS 開啟一次；直接以 `file://` 開啟不適合作為正式離線安裝方式。
- 法規封存會保留作答證據，但不再列入新的法條訓練與每日任務。
